How do I get a session file?
  1. Browser extension (easiest): sign in at southwest.com in Chrome or Firefox, open a cookie export extension (for example Cookie-Editor), choose Export → JSON while on southwest.com, and paste the result above.
  2. Helper script: on a computer with Python, run python -m app swa-login from this project, sign in in the window that opens, and upload the storage_state.json it writes.

Sessions expire. If searches start failing you'll get an email; upload a fresh session.
